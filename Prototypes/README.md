# Prototypes

Use this directory for experiments that answer one question quickly, such as:

- Which mesh topology produces a convincing paper-like corner curl?
- What gesture threshold avoids accidental activation?
- Is a still snapshot sufficient, or is live capture necessary?
- How quickly can an overlay be aligned with a moving source window?

Prototype code must not be imported by production targets. When an experiment
succeeds, reimplement the learned behavior behind the appropriate module API.
