# Peel Window 使用说明

[English](USER_GUIDE_EN.md) · [下载页面](https://github.com/fyyyaug/peel-window/releases/tag/v0.1.0-beta.3)

Peel Window 可以像翻书一样临时卷起窗口，查看它背后的画面；松开鼠标后，窗口会回弹恢复。

## 1. 下载与安装

- 支持 Apple 芯片 Mac（M 系列），macOS 14 或更高版本。
- 下载 [PeelWindow-0.1.0-beta.3-macos-arm64.dmg](https://github.com/fyyyaug/peel-window/releases/download/v0.1.0-beta.3/PeelWindow-0.1.0-beta.3-macos-arm64.dmg)。只需这一个文件，不需要下载 Source code、Xcode 或其他依赖。
- 打开 DMG，将 `PeelWindow.app` 拖入 `Applications`（应用程序）。然后从“应用程序”启动 PeelWindow。

当前测试版未经过 Apple 公证。若首次启动被拦截，请在尝试打开后进入“系统设置 → 隐私与安全性”，找到 PeelWindow 的提示并选择“仍要打开”。只批准你信任来源的应用。

Peel Window 会使用 macOS 语言偏好列表中第一个受支持的语言；没有匹配时使用英语。可在“系统设置 → 通用 → 语言与地区 → 应用程序”中单独设置 Peel Window 的语言，然后重新打开应用。

## 2. 首次使用：允许屏幕录制

1. 在“桌面翻页”页面点击“设置权限”。
2. 在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”（部分系统名为“屏幕录制”）中允许 PeelWindow。
3. 如果系统提示“退出并重新打开”，按提示重启应用。
4. 返回应用，确认显示“录屏权限已就绪”；必要时点击“重新检查”。

屏幕录制权限用于捕获窗口及其背后的画面，是桌面翻页功能的必要条件。

## 3. 开始翻页

1. 打开“桌面持续翻页”开关。
2. 在 Word、Xcode 或其他受支持应用中，将鼠标移到一个已启用、没有被遮挡的窗口角落。
3. 停留达到设置的时间后，角落会显示提示标记。
4. 从标记中央按住鼠标，向窗口内部拖动。左右、上下移动可以改变卷曲方向和翻开范围。
5. 松开鼠标，窗口回弹恢复。将鼠标移开角落后再靠近，即可再次翻页。

切换应用、移动窗口或关闭某个窗口不会关闭总开关。无需为每个应用手动选择窗口或点击“捕获”。

如果第一次画面还在准备中，标记仍可先显示；按住并拖动时，程序会在画面准备好后接上操作。提前松手会取消这次操作。

## 4. “桌面翻页”页面

| 设置 | 用途 |
| --- | --- |
| 桌面持续翻页 | 开启或关闭桌面翻页。也可在 PeelWindow 应用菜单中切换“启用桌面翻页”。 |
| 四个角落 | 分别启用左上、右上、左下、右下角，至少保留一个。设置决定可以从哪里开始拖动。 |
| 最大翻开范围 | 10%–100%，限制能够翻开的最大区域。 |
| 回弹力度 | 0.25×–2×，控制松手后的回弹手感。 |
| 鼠标悬停生效时间 | 0–10 秒，支持直接输入三位小数，如 `0.100`、`0.010`、`0.001`。设为 `0` 不增加人为等待。 |

零延迟不等于物理上的零耗时：鼠标检测、屏幕刷新与画面准备仍需要时间。程序会在鼠标靠近角落时提前准备画面，提示标记的显示不再等待截图完成。

## 5. “提示标记”页面

也可以通过“PeelWindow → 设置…”或 `⌘,` 打开标记设置。

| 设置 | 范围或说明 |
| --- | --- |
| 大小 | 24–140 点；较小窗口会自动限制标记大小，避免超出窗口。 |
| 不透明度 | 10%–100%；数值越低越透明。 |
| 颜色 | 使用颜色选择器自定义。 |
| 鼠标悬停生效时间 | 与主页面同步，决定停留多久显示标记。 |
| 显示时长 | 0–30 秒；`0` 表示鼠标停留期间持续显示。 |
| 恢复默认设置 | 恢复标记外观和时间设置，不改变翻开范围或回弹力度。 |

页面提供外观预览。定时隐藏后，将鼠标移开角落再靠近即可重新显示。拖动期间不会因为显示时长到期而中断。

设置自动保存；重新启动应用后会保留桌面模式开关及各项偏好。需要手动启动应用，本版本没有添加开机自启动。

## 6. “翻页预览”页面

- **示例窗口**：使用内置样本，不需要捕获真实窗口。
- **预览 50%**：显示静态翻页效果；点击“继续”返回交互状态。
- **查找窗口 → 选择窗口 → 捕获**：在应用内预览真实窗口快照。
- **自动检测实际下层窗口**：为预览自动寻找角落下方的窗口；也可手动选择下层窗口。

这些手动捕获操作用于预览。日常桌面翻页只需要开启总开关。

## 7. 暂停与退出

关闭主页面的“桌面持续翻页”，或取消应用菜单中的“启用桌面翻页”，即可停止桌面翻页。关闭主设置窗口不等于退出后台应用。要完全退出，请使用“PeelWindow → 退出 PeelWindow”。

## 8. 常见问题与当前限制

**没有提示标记**

确认总开关已开启、录屏权限已就绪，并且鼠标位于已启用的可见角落。检查悬停时间和不透明度；等待已设置的时间。提示已自动隐藏时，移开鼠标再靠近。

**更新后权限开关已开，但仍提示没有权限**

退出应用后，在系统录屏权限列表中删除旧 PeelWindow 项，再添加 `/Applications/PeelWindow.app` 并启用；按系统提示重新启动。当前本地临时签名测试版更新后可能需要刷新授权记录。

**下层画面没有实时变化**

翻页使用静态截图，不是实时视频。移开角落再开始一次翻页以重新准备画面。

**某些窗口不能翻页**

当前支持完整位于主显示器内、大小足够的普通窗口；暂不支持多显示器、跨屏窗口及所有系统特殊窗口。被遮挡的角落不会接收翻页输入。受保护内容可能无法正常捕获。本测试版不承诺覆盖所有应用或无缺陷运行。
